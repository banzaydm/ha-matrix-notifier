# Matrix Notifier для Home Assistant

Интеграция для отправки уведомлений из Home Assistant в комнаты Matrix через удобный UI: текст, снимки камер и видеозаписи с RTSP.
Задача проекта - все настраивать через графический интерфейс без необходимости править конфигурации.
## Возможности

- **Config Flow** — настройка через UI, без YAML
- **Правила уведомлений** (subentries):
  - Триггер по **entity** (изменение состояния) или по **automation** (`automation_triggered`)
  - Фильтр по целевому состоянию (to_state)
  - Шаблоны сообщений (Jinja2): `{{ name }}`, `{{ entity_id }}`, `{{ state }}`, `{{ trigger_name }}` и др.
  - Каналы доставки на каждое правило: 📨 Matrix, ✈️ Telegram или оба сразу
  - Cooldown 30 сек на правило
- **Telegram-канал** (необязательно) — собственный клиент Bot API:
  - Токен бота от @BotFather, несколько чатов (личка/группа/канал)
  - Текст, снимки и видео уходят и в Matrix, и в Telegram
  - Настройка и тест из панели (без YAML)
- **Медиа** — снимок 📷 / видео 🎬 / снимок + видео 📷🎬:
  - Снимок: снимок с `camera` entity (JPEG)
  - Видео: реальная RTSP-запись через ffmpeg (15 fps), длительность 5–60 сек, качество `original`/`720p`/`480p`
  - Автоматический fallback: `async_get_stream_source` → ONVIF-конфиг → проба RTSP-URL → слайдшоу из снимков
- **Веб-панель** в сайдбаре HA:
  - Управление правилами (CRUD, ▶️ тестирование)
  - Запись видео с выбором камеры/комнаты/длительности/качества
  - Управление комнатами (создание, участники, invite/kick)
  - Статус подключения
- **Комнаты** — выбор из joined rooms, автозагрузка
- **Notify-платформа** `notify.matrix_notifier` для автоматизаций
- **Служба `matrix_notifier.send`** — отправка с выбором комнаты
- **REST API** для панели (`/api/matrix_notifier/...`)
- **Автоматическое обновление токенов** — переподключение при разрыве
- **Русский интерфейс**

## Установка через HACS
1. HACS → меню ⋮ → Custom repositories
2. Ввести https://github.com/banzaydm/ha-matrix-notifier, тип Integration
3. В каталоге HACS появится «Matrix Notifier» → Install → перезапуск HA
4. Настройки → Интеграции → + → Matrix Notifier → вводит свой homeserver, логин/пароль бота, device ID
5. Панель управления — в сайдбаре HA
## Установка

1. Скопируйте папку `custom_components/matrix_notifier` в `/config/custom_components/` вашего HA
2. Перезапустите Home Assistant
3. Настройки → Интеграции → Добавить → **Matrix Notifier**

## Настройка

1. **Шаг 1 — Подключение:**
   - Homeserver URL: `https://ваш-сервер`
   - Имя пользователя: `bot`
   - Пароль
   - ID устройства: оставьте `HANOTIFIER` (фиксированный ID = стабильный токен)

2. **Шаг 2 — Комнаты:** выберите комнаты из списка

## Использование в автоматизациях

```yaml
action: notify.matrix_notifier
data:
  message: "Протечка воды в ванной!"
```

Или через службу:

```yaml
service: matrix_notifier.send
data:
  message: "Текст уведомления"
  room_id: "!roomid:server"  # опционально
```

## Шаблоны в сообщениях

| Переменная | Описание |
|---|---|
| `{{ name }}` | Friendly name сущности (или датчика-триггера для automation-правил) |
| `{{ entity_id }}` | ID сущности (или датчика-триггера) |
| `{{ state }}` | Текущее состояние |
| `{{ rule }}` | Название правила |
| `{{ trigger_name }}` | Friendly name сработавшего датчика (automation-правила) |
| `{{ trigger_entity }}` | ID сработавшего датчика (automation-правила) |
| `{{ now() }}` | Текущее время |

## Требования

- Home Assistant 2024.1.0+
- ffmpeg/ffprobe в контейнере HA (есть в стандартном образе)
- Камеры с доступным RTSP (ONVIF-интеграция или прямые RTSP-URL)
